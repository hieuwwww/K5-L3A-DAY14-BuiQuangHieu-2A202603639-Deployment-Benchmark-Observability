# Day 14 Submission Artifacts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the K5 submission documents and evidence layout without fabricating student-authored answers or run-derived proof.

**Architecture:** Add root-level submission documents aligned to `SUBMISSION.md`, `CHECKPOINTS.md`, and `DAY14_DELIVERY_CHECKLIST.md`. Fill only repository-derived instructions and prompts; clearly label personal answers, live results, screenshots, and measurements for the student to supply.

**Tech Stack:** Markdown; existing repository instructions and Part 7 report template.

**Spec:** `docs/superpowers/specs/2026-11-25-day14-lab-completion-design.md`

## Global Constraints

- K5-specific directions in root `README.md` and `CHECKPOINTS.md` override generic checklist examples.
- Do not fabricate personal answers, cloud URLs, screenshots, performance measurements, image sizes, alert timings, or command outputs.
- `RULES.md` requires an AI log: what was asked, what was received, and how the student changed and tested it. Do not claim student changes or tests that have not happened.
- Required output locations are root-level `MISSION_ANSWERS.md`, `DEPLOYMENT.md`, `BENCHMARK_REPORT.md`, `reports/`, `benchmark-results/`, and `screenshots/`; empty directories are not evidence.
- Part 7 JSON/CSV must be produced by the documented commands and copied from their specified subdirectories.

## Review Focus

- Student-authored answer prompts must not be phrased as completed first-person claims.
- Every required artifact listed in `SUBMISSION.md` must be represented, including Part 3 platform comparison/Cloud Run summary and Part 7 screenshots/CSV/JSON.
- Commands must reflect K5 corrections (ports, endpoints, Compose project names, directories, and `--out` behavior).
- Do not leave secrets in commands or examples; use placeholders or environment variables and warn to redact tokens.
- Benchmark template values should remain blank/marked pending until matching reports exist.
